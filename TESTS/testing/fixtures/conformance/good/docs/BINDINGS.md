# goodp.nvim bindings

## Keymaps

| Config key | Suggested lhs | Action |
| --- | --- | --- |
| `open` | `<leader>go` | `:Goodp open` |

## Commands

| Command | What |
| --- | --- |
| `:Goodp [open\|close]` | Open or close the window |

## Autocmds

Group `GoodpGroup`: `BufReadPost` notes the opened buffer.
